## How to Regenerate

Run the following command (requires a GitHub personal access token):

```bash
# Using GitHub CLI
gh api user/starred --paginate --jq '.[].full_name'

# Using the Python script in this repository
python list_starred_repos.py --token YOUR_GITHUB_TOKEN --output STARRED_REPOSITORIES.md
```

Or set the `GITHUB_TOKEN` environment variable and omit `--token`:

```bash
export GITHUB_TOKEN=your_token_here
python list_starred_repos.py --output STARRED_REPOSITORIES.md
```
